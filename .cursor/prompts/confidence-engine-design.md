# Confidence Engine Design Prompt

Design the **Confidence Engine** combining features into scores.

Deliver:

- Feature vector specification (deterministic signals + verification outcomes).
- Model choice: calibrated logistic / tree ensemble / hand-tuned weighted schema — justify interpretability.
- Training/evaluation methodology using labeled datasets.
- Thresholds for internal review vs external publication.
- Explainability outputs: top positive/negative features per finding.
- Guardrails banning raw LLM probability as score.

Include operational monitoring for calibration drift.
